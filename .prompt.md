Implement a subscription management system in Django with the following requirements:

1. Database Configuration:
   - Create models to store subscription details at user app including:
     - Subscription start date
     - Subscription type (Free/Commercial)
     - Duration period
     - Other relevant metadatas/ text area.
     - Billing amount
     - Subscription status (active/expired)
     - subscription grace period (if applicable)

2. User Interface Requirements:
   - Add "Subscription Details" link to the main navigation menu
   - Create a subscription details page showing:
     - Subscription type (Free/Commercial)
     - Current subscription status
     - Remaining days until expiration
     - Next billing date
     - Payment amount

3. Access Control:
   - Implement middleware to check subscription status
   - Redirect expired subscriptions to a dedicated subscription information page
   - Prevent login access for expired subscriptions
   - Display clear messaging about subscription status

4. Technical Specifications:
   - Use Django's built-in authentication system
   - Implement proper date handling/ remaining days calculation
