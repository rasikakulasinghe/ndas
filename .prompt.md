Design and implement a responsive Patient Timeline Card component that visualizes a patient's complete medical history from birth to present, with the following specifications:

Display Requirements:
- Start with patient's birth date as the initial event
- Present all medical events in strict chronological order
- Include Video assessments, Other assessments, clinical events, and management actions
- Show date, time, event type, and concise description for each entry

Visual Elements:
- Implement distinct icons for event categories:
  * Stethoscope for medical assessments
  * Pill/capsule for medications
  * Video camera for recorded sessions and camera with eye for video assessments
  * Syringe for injections and immunizations
  * Physiotherapy icon for physical therapy sessions
  * Medical form for written assessments
  * Custom icons for other event types as needed
  * Other sections as appropriate

Layout & Structure:
- Create a vertical timeline visualization
- Group events by type with collapsible sections
- Use clear typography and hierarchical headings
- Maintain consistent spacing and alignment
- Ensure sufficient contrast for readability

Responsive Design:
- Adapt layout for desktop, tablet, and mobile viewports
- Maintain readability across all screen sizes
- Implement touch-friendly interaction on mobile devices
- Optimize performance for smooth scrolling with large datasets

Technical Considerations:
- Use semantic HTML for accessibility
- Enable keyboard navigation
- Consider pagination or virtual scrolling for extensive histories
