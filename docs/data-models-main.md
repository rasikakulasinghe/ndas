## Entity Relationship Overview

```
CustomUser (users)
    │
    ├──(added_by / last_edit_by)──────────────► ALL models (via UserTrackingMixin)
    │
    └──(authorized_gpa_discharges)────────────► GeneralPaediatricAssessment
    └──(bookmarks / owner)────────────────────► Bookmark

Patient (patients)
    │
    ├── M2M ──► IndicationsForGMA
    │
    ├── FK ◄── GMAssessment
    │              └── O2O ──► Video (video)
    │              └── M2M ──► DiagnosisList
    │
    ├── FK ◄── HINEAssessment
    ├── FK ◄── CDICRecord
    ├── FK ◄── GeneralPaediatricAssessment (GPA)
    ├── FK ◄── DevelopmentalAssessment (DA)
    ├── FK ◄── Attachment
    ├── FK ◄── Problem (problemlist)
    └── FK ◄── [Bookmark.object_id — generic, bookmark_type="Patient"]

Video (video) ──O2O──► GMAssessment

Bookmark (generic FK pattern):
    bookmark_type + object_id → Patient | Video | GMAssessment | HINEAssessment
                                Attachment | DevelopmentalAssessment
                                CDICRecord | GeneralPaediatricAssessment

ReportTemplate (reports) — standalone
ReportConfig (reports) — standalone key-value store
```

## Base Classes (All Models)

Every model inherits both:

| Mixin | Fields Provided |
|-------|----------------|
| `TimeStampedModel` | `created_at` (DateTimeField, auto_now_add), `updated_at` (DateTimeField, auto_now) |
| `UserTrackingMixin` | `added_by` (FK→CustomUser, SET_NULL, null), `last_edit_by` (FK→CustomUser, SET_NULL, null) |

Auto-populated by `UserActivityMiddleware` — do NOT set manually in views.

### `DevelopmentalAssessment` (DA)

Multi-domain developmental screening (0–72 months).

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `patient` | FK → Patient | CASCADE, db_index, related_name="developmental_assessments" | |
| `date_of_assessment` | DateTimeField | db_index | Cannot be future or before birth |
| `gm_age_from` / `gm_age_to` | PositiveSmallIntegerField | 0–72, null/blank | Gross motor dev age range (months) |
| `gm_details` | TextField | null, blank | GM observations |
| `fmv_age_from` / `fmv_age_to` | PositiveSmallIntegerField | 0–72, null/blank | Fine motor + vision dev age range |
| `fmv_details` | TextField | null, blank | FMV observations |
| `hsl_age_from` / `hsl_age_to` | PositiveSmallIntegerField | 0–72, null/blank | Hearing, speech, language dev age range |
| `hsl_details` | TextField | null, blank | HSL observations |
| `seb_age_from` / `seb_age_to` | PositiveSmallIntegerField | 0–72, null/blank | Social, emotional, behavioral dev age range |
| `seb_details` | TextField | null, blank | SEB observations |
| `assessment_done_by` | CharField(200) | db_index | Assessor name |
| `comment` | TextField | null, blank | Additional notes |
| `is_dx_normal` | BooleanField | db_column="isDxNormal", db_index, auto-updated | Set automatically via `save()` from `is_normal` property |

**Domain Validation:** For each domain, `age_to >= age_from` required.

**`is_normal` Logic:** True if `age_from ≤ patient_age_months ≤ age_to` for all populated domains.

**Composite Indexes:**
- (patient, -date_of_assessment)
- (is_dx_normal, date_of_assessment)
- (assessment_done_by)

## App: `video`

### `Video`

Clinical assessment recordings.

| Field | Type | Constraints | Notes |
|-------|------|-------------|-------|
| `patient` | FK → Patient | CASCADE, db_index, related_name="videos" | |
| `video_file` | FileField | upload_to=get_video_path_file_name, validators=[validate_video_file] | Max 2GB |
| `title` | CharField | db_index | Video title |
| `recorded_on` | DateField/DateTimeField | db_index, validators=[validate_recording_date] | Not future, not >10 yrs ago |
| `duration_seconds` | IntegerField/FloatField | null, blank | Auto-extracted via moviepy/ffprobe |
| `file_size_bytes` | PositiveBigIntegerField | null, blank | Auto-extracted |
| `processing_status` | CharField | choices=PROCESSING_STATUS, db_index | pending/uploading/processing/completed/failed |
| `resolution` | CharField | null, blank | e.g., "1920x1080" |

**UniqueConstraint:** (patient, recorded_on, title) — no duplicate video entries per date per patient.

**Custom Manager:** `VideoManager` with queryset methods:
- `with_assessment_status()` — annotates with GMAssessment existence
- `new_videos_only()` — videos without GMAssessment
- `assessed_videos_only()` — videos with GMAssessment

**Reverse Relation from GMAssessment:** `video.gmassessment` (OneToOne reverse)
