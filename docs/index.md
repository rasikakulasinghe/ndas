## Critical Rules (Summary)

> See [CLAUDE.md](../CLAUDE.md) for the full authoritative rules.

1. **All models** must inherit `TimeStampedModel, UserTrackingMixin`
2. **All choices** go in `ndas/custom_codes/choice.py` — never inline
3. **All validators/sanitizers** from `ndas/custom_codes/validators.py` or `sanitization.py`
4. **All deletes** via `delete_helpers.py` — never `obj.delete()` directly in views
5. **All views** use `get_object_or_404()` — never `.objects.get()`
6. **Middleware order** is critical — never reorder
7. **Frontend** is AdminLTE 3.2 + Bootstrap 4.6 — never change versions
8. **Secrets** in `.env` only — never hardcoded

## Medical Domain Quick Reference

| Term | Meaning |
|------|---------|
| BHT | Bed Head Ticket — primary patient identifier |
| NNC | Secondary patient number |
| PTC | Patient tracking code |
| GMA | General Movement Assessment (video-based, O2O with Video model) |
| HINE | Hammersmith Infant Neurological Examination (score 0–78, normal >73) |
| CDIC | Child Development and Intervention Centre (rehabilitation tracking) |
| GPA | General Paediatric Assessment (routine clinical evaluation) |
| DA | Developmental Assessment (4 domains: GM, FMV, HSL, SEB; age 0–72 months) |
| POG | Period of Gestation (weeks + days, 20–44 weeks) |
| APGAR | Newborn health score at 1, 5, 10 minutes (0–10 each) |
| OFC | Occipital-frontal circumference (head circumference) |
| PHM | Public Health Midwife |
| MOH | Medical Officer of Health |
